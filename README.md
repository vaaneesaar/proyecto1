# Vanette — Portafolio de Vanesa Lilian Rodríguez Cortés

**Vanesa Lilian Rodríguez Cortés** — Diseñadora Gráfica

## Sobre el proyecto

Este repositorio contiene el portafolio web de Vanette, una diseñadora gráfica especializada en branding, identidad visual y diseño de empaque. El sitio incluye una landing page CV completa con diseño responsivo, sistema de diseño visual y documentación del proyecto.

## Estructura del repositorio

```
├── index.html          # Landing page CV principal
├── design.html         # Página del sistema de diseño
├── DESIGN.md           # Especificación del sistema de diseño
├── CV.md               # Contenido del CV en Markdown
├── Arquitectura-CV-VLRC.docx
├── MiSistemadeDiseño_VLRC.docx
├── assets/
│   ├── fonts/          # Fuentes tipográficas (Hypop, NewYork, Avenir)
│   ├── img/            # Imágenes del portafolio
│   ├── logo/           # Logos e isotipos
│   └── editables/      # Archivos editables (Adobe Illustrator)
└── .gitignore
```

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 con variables de diseño (tokens)
- JavaScript vanilla
- SVG para decoraciones y olas
- Google Fonts + fuentes personalizadas
